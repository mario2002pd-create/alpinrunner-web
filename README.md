# Alpinrunner Chur – neue Website (Design-Vorschlag)

Statische Neugestaltung von https://www.alpinrunner.ch mit allen Inhalten (Agenda, Laufstrecken, News, Team, Shop, Partner, Links).

- `index.html`, `team.html`, `agenda.html`, `laufstrecken.html` … fertige Seiten (GitHub Pages)
- `style.css`, `site.js` gemeinsames Design und Skripte (Filter der Laufstrecken, Lightbox, Agenda)
- `assets/`, `files/`, `img/`, `team/` Bilder und PDFs der bisherigen Website
- `tools/` Skripte, mit denen der Inhalt von der bestehenden Website gelesen und neu aufgebaut wird (`crawl.py`, dann `build.py`)

Hinweis: Die Formulare (Kontakt, Alpinrunner Freund, Marktplatz, News einreichen) laufen weiterhin auf der bestehenden Website.
Dies ist eine Momentaufnahme der Inhalte; die Quelle bleibt bis auf Weiteres alpinrunner.ch.
